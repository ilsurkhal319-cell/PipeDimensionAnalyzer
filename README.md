# PipeDimensionAnalyzer

Программа рассчитывает суммарную длину трубопровода по изометрическим чертежам в PDF,
включая ответвления и исключая вложенные размеры.

## Запуск

Скачайте или клонируйте репозиторий, откройте его папку как проект в PyCharm и выполняйте
следующие команды во встроенном терминале PyCharm. Требуется Python 3.11 или новее.

Windows (PowerShell):

```powershell
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Ubuntu/Debian:

```bash
sudo apt install python3-tk
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
```

API-ключ можно получить после регистрации в личном кабинете VseGPT:
https://vsegpt.ru/User/API. Пополните баланс, скопируйте ключ и укажите его как
`OPENAI_API_KEY` в файле `.env`, затем запустите интерфейс.

Windows:

```powershell
.venv\Scripts\python.exe gui.py
```

Ubuntu/Debian:

```bash
.venv/bin/python gui.py
```

В интерфейсе выберите PDF, укажите номер листа и нажмите «Запустить анализ».

## Краткое описание подхода

PyMuPDF извлекает из PDF текст и векторную геометрию. Программа находит линейные размеры,
после чего выполняются два независимых AI-этапа: первая vision-модель определяет вложенные
размеры, вторая определяет основную трассу и ответвления. Итоговая сумма вычисляется
программно. Результат сохраняется в виде таблицы, JSON и размеченного PDF.

На обоих этапах по умолчанию используется `vis-google/gemini-3-flash-pre`, но с разными
изображениями и системными промтами. Модель выбрана как компромисс между качеством анализа
чертежей, скоростью и стоимостью. Отдельный OCR-сервис не используется.

## Известные ограничения

- PDF должен содержать достаточно различимый текст и размерные линии
- интерфейс обрабатывает один выбранный лист за запуск;
- качество результата зависит от стабильности ответа vision-модели.
